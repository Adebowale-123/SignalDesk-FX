MetaTrader 5 bridge

{% if trader.bridge_online %}Online{% else %}Offline{% if trader.bridge_seen_at %} · last seen {{ trader.bridge_seen_at|timesince }} ago{% endif %}{% endif %}

A small program on a Windows computer next to MT5: it collects orders from SignalDesk every 20 seconds, places them with stop loss and take profit, and reports results. The computer must stay on (and MT5 open) while you want trading; stops and targets stay at the broker either way.

  1. Install MetaTrader 5 from your broker, log in to your demo account, and switch on Algo Trading. Also Tools → Options → Expert Advisors → tick “Allow algorithmic trading”.
  2. Install Python for Windows from python.org — tick “Add python.exe to PATH”.
  3. Download the bridge, double-click it, and keep the window open. It shows “Connected”.
